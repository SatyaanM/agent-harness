## [0.1.0] - 2026-08-18

### Added
- Next.js and React 19 web dashboard featuring a persistent split-panel workspace layout.
- Interactive chat stream with runtime synchronization, retry actions, token-budget meters, and transcript drawer views.
- Knowledge inbox file explorer supporting upload, drag-and-drop, rename, and file deletion.
- Registry-backed in-place file renderers and editors for Markdown, Excalidraw whiteboards, PDF documents, and Monaco code.
- Client-side Zustand stores managing session history, runtime execution state, agent roster, and plugin registries.
- REST and Socket.IO client adapters with response size budgeting and live connection recovery.
